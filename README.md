# A Aventura das Letras

Jogo educativo (HTML + CSS + JavaScript puro) para crianças de 5 a 6 anos, com 40 perguntas em 8 mundos.
Abra o `index.html` com a pasta inteira junto (assets/, audio/, img/). Não precisa de servidor.

- `audio/questao-01.mp3 ... questao-40.mp3`: narração de cada pergunta (troque o arquivo mantendo o nome).
- `assets/`: logo e fundo da tela de início.
